Features

Small app. Sharp answers.

Everything is built around one idea: the screen is the context.

Screen Analysis

Displays, windows, or a drawn region on any monitor. Preview and redact sensitive spots before sending.

Guard Mode

A permanent scope lock. Jailbreaks and harmful requests are refused locally, before a single byte reaches a provider.

Local Models

Chelp can install Ollama itself, pull models with live progress, and keep the active model warm for two hours.

Floating Assistant

A compact always-on-top window that collapses to an orb. Ask without leaving the app you are debugging.

Your Model, Exactly

The answer always comes from the profile marked Active. No silent swaps, no surprise Qwen. Backup AI is opt-in and labeled.

Private by Default

Keys are encrypted with the OS keychain — DPAPI on Windows, libsecret on Linux. Screenshots stay on disk until you send. History is local and can be wiped.

Always on

A helper. Not a Swiss Army knife.

Chelp is built to explain what broke — not to run commands, browse for you, or become someone’s tool. Guard Mode sits in the main process, before any network request.

  • Only errors, troubleshooting, software, settings, and general questions.
  • Jailbreaks and harmful requests are blocked on-device.
  • Text inside screenshots is treated as data, never as instructions.
  • There is no off switch in the UI — and no tool access to abuse.

FAQ

Before you ask.

Do I need an API key?

For cloud providers, yes — paste a key or use one-click OpenRouter sign-in. Local models through Ollama or LM Studio need no key at all.

Does it take screenshots on its own?

No. A capture happens only when you click Capture or press the hotkey. You see a preview, can redact parts of it, and nothing is uploaded until you press Send.

Can I use it completely offline?

Yes. Chelp can install its own Ollama runtime and download a model, then work with no network connection. Cloud profiles are optional.

Can I turn Guard Mode off?

No. It is part of the request pipeline, not a setting. The model is also told it cannot run commands or control your computer — and the app has no tools to do it.

Which models are supported?

DeepSeek, OpenRouter, OpenAI, Google Gemini, any OpenAI-compatible endpoint, and local models via Ollama or LM Studio. Vision models are marked, so screen analysis uses a model that can actually see images.

Is there a macOS or Linux build?

Linux is available now as a portable x64 archive, with the same features as Windows. AppImage and deb packages are published with releases. macOS is not supported yet — Chelp leans on native window, tray, and input APIs on each platform.

How do updates work?

Download the latest release and run it over the old version. Conversations and settings stay in %APPDATA%\Chelp AI on Windows and in ~/.local/share/Chelp AI on Linux.
